# 帝王竞技场：三人炸金花联机网页版

这是一个 Node.js + Express + Socket.IO 的实时多人网页游戏。支持三人好友房和随机匹配，使用虚拟筹码，不含真钱下注、充值、提现或现金奖品。

## 项目结构

- `server.js`：服务端权威逻辑、洗牌发牌、房间、轮次、比牌和结算
- `public/`：手机网页前端
- `render.yaml`：Render 部署配置
- `package.json`：依赖和启动命令

## 重要：当前版本的规则范围

这是可运行的 MVP（最小可用版本），每桌最多 3 人。包含创建好友房、房间号加入、随机匹配、轮流行动、跟注、加注、弃牌、比牌、摊牌结算。为保持规则简单，当前没有“看牌后下注翻倍”、旁观、聊天、账号系统、永久战绩和断线续局；随机匹配房间在凑齐三人后从匹配队列移除。若玩家中途断线，会按离开处理。

牌型大小：豹子 > 顺金 > 金花 > 顺子 > 对子 > 单张；A-2-3 作为最小顺子。相同牌型按对应点数比较，完全相同为平手时比牌方不淘汰对手。

## 用 iPhone 部署（无需本地电脑，但需要网站托管账号）

最省事的路线是 GitHub + Render。手机浏览器操作可能不如电脑方便，但可以完成。

### A. 上传代码到 GitHub
1. 在 Safari 打开 `https://github.com`，登录或注册账号。
2. 新建一个 Repository，名字例如 `zhajinhua-arena`，设为 Public（Render 免费部署更简单），不要勾选自动生成 README。
3. 在仓库页面选择 **Add file → Upload files**。
4. 将本 ZIP 解压后，把里面的文件和 `public` 文件夹上传到仓库根目录。若 iPhone 不方便上传整个文件夹，可先在“文件”App 解压 ZIP，再通过 GitHub 网页上传；确保 `server.js`、`package.json`、`render.yaml` 在仓库根目录，前端文件在 `public` 文件夹内。
5. 点击 Commit changes。

### B. 部署到 Render
1. Safari 打开 `https://render.com`，注册并登录。
2. 选择 **New → Web Service**，连接 GitHub，并授权访问刚才的仓库。
3. Render 通常会识别 `render.yaml`。若需要手动填写：
   - Runtime：Node
   - Build Command：`npm install`
   - Start Command：`npm start`
   - Health Check Path：`/health`
4. 点击 Deploy。等待构建成功，Render 会提供一个 `https://xxxx.onrender.com` 网址。
5. 在 iPhone Safari 打开这个网址；把网址发给朋友，他们也可以用手机浏览器打开同一个地址联机。

### C. 开始玩
1. 一个人点击“创建好友房”，把 6 位房间号发给朋友。
2. 第二个人输入房间号加入。
3. 第三个人也加入；满 3 人后房主点击“房主开始发牌”。
4. 想随机匹配时，三个人分别点击“随机匹配”；服务端会把玩家放入同一个等待房，满 3 人后房主开始。

## 注意事项
- Render 免费实例可能在空闲时休眠，首次访问可能需要等待启动。
- 这是演示性质的实时房间服务，房间状态存在服务器内存中；服务器重启后房间会清空。
- 当前没有持久化账号/战绩，也没有生产级防作弊审计、速率限制或内容审核。不要用于真钱赌博或商业运营。
- 若公开部署，建议后续增加持久化数据库、玩家身份验证、断线重连、速率限制、隐私政策和安全审查。
- 不要把私密密钥提交到 GitHub。本项目暂时不需要任何密钥。
